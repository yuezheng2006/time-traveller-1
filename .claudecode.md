# Claude Code Configuration

This file provides context for Claude Code, integrating rules from the `.cursor` directory.

## Core Rules Integration

- **API Endpoints**: Follow [steps/api/ instructions](.cursor/rules/motia/api-steps.mdc).
- **Background Tasks**: Follow [steps/events/ instructions](.cursor/rules/motia/event-steps.mdc).
- **Scheduled Tasks**: Follow [cron steps guide](.cursor/rules/motia/cron-steps.mdc).
- **State Management**: Use `state.set()` and `state.get()` per [state guide](.cursor/rules/motia/state-management.mdc).
- **Real-time Streaming**: Use `streams` per [streaming guide](.cursor/rules/motia/realtime-streaming.mdc).
- **Workbench UI**: Custom nodes per [ui-steps guide](.cursor/rules/motia/ui-steps.mdc).
- **Workflow Visualization**: Use virtual connections per [virtual-steps guide](.cursor/rules/motia/virtual-steps.mdc).

## Project Guidelines

For detailed development commands, architecture overview, and code patterns, refer to the main [CLAUDE.md](./CLAUDE.md) file.

### Key Commands
- `npm run backend`: Start Motia backend (Port 3000)
- `npm run dev`: Start Vite frontend (Port 5173)
- `npm run build`: Build for production

### File Patterns
- Steps: `steps/**/*.step.ts`
- Services: `services/**/*.ts`
- Components: `frontend/components/**/*.tsx`
